# Skills do projeto

Habilidades ("como fazer X neste repositório") reutilizáveis por qualquer pessoa ou agente que trabalhe
no ECommerceLES. Cada pasta tem um `SKILL.md` com um procedimento executável, não com teoria.

| Skill | Use quando |
| --- | --- |
| [`angular-feature`](angular-feature/SKILL.md) | Criar uma nova feature/página (Cliente ou Admin) |
| [`api-response-contract`](api-response-contract/SKILL.md) | Consumir/expor qualquer endpoint (`Response<T>`) |
| [`mock-to-backend`](mock-to-backend/SKILL.md) | Plugar o backend ASP.NET Core real no lugar dos mocks |
| [`admin-crud`](admin-crud/SKILL.md) | Criar uma listagem + formulário no back-office |
| [`design-system`](design-system/SKILL.md) | Criar/alterar componentes visuais |
| [`auth-evolution`](auth-evolution/SKILL.md) | Ligar JWT, login persistente e autorização |
